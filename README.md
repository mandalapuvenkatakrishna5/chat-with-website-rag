Chat With Multiple PDFs

This is a Streamlit web application that allows users to upload multiple PDF documents and chat with an AI system based on the content of these PDFs.

The application uses Retrieval Augmented Generation (RAG) techniques with NLP, embeddings, and Large Language Models to understand document content and provide accurate answers based on uploaded PDFs.

Features
Upload Multiple PDFs: Users can upload multiple PDF documents and process them together.
Chat Interface: Users can interact with an AI chatbot and ask questions related to uploaded PDF content.
PDF Text Extraction: Extracts text from PDF documents for further processing.
NLP Processing: Performs text chunking, embedding generation, and semantic search.
Vector Database: Stores document embeddings for efficient similarity-based retrieval.
AI Response Generation: Generates context-aware answers using Hugging Face / LLM models.
Interactive Experience: Provides a simple and user-friendly Streamlit interface for exploring PDF information.
