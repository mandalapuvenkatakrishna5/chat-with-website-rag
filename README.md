Chat With Multiple PDFs

This is a Streamlit web application that allows users to upload multiple PDF documents and chat with an AI system based on the content of these PDFs.

The application uses Retrieval Augmented Generation (RAG) techniques with NLP, embeddings, and Large Language Models to understand document content and provide accurate answers based on uploaded PDFs.

Features
Upload Multiple PDFs: Users can upload multiple PDF documents and process them together.
Chat Interface: Users can interact with an AI chatbot and ask questions related to uploaded PDF content.
PDF Text Extraction: Extracts text from PDF documents for further processing.
NLP Processing: Performs text chunking, embedding generation, and semantic search.
Vector Database: Stores document embeddings for efficient similarity-based retrieval.
AI Response Generation: Generates context-aware answers using Hugging Face / LLM models.
Interactive Experience: Provides a simple and user-friendly Streamlit interface for exploring PDF information.

# Chat With Website using RAG

## Project Description

Chat With Website is a Streamlit-based AI application that allows users to interact with any website content through natural language conversations.

The application uses Retrieval-Augmented Generation (RAG) architecture to extract website content, split it into meaningful chunks, generate embeddings, store them in a vector database, and retrieve relevant information to answer user queries accurately.

The system combines LangChain, Hugging Face models, and Chroma Vector Database to provide an intelligent question-answering experience based on website information.

---

## Features

- 🌐 **Website URL Input**
  - Users can provide any website URL as input.

- 📄 **Web Content Extraction**
  - Automatically extracts text content from websites using web loaders.

- ✂️ **Text Processing**
  - Splits large website content into smaller chunks for efficient retrieval.

- 🧠 **Semantic Search**
  - Creates embeddings using Hugging Face embedding models.

- 🗄️ **Vector Database**
  - Stores embeddings using Chroma Vector Database.

- 💬 **AI Chat Interface**
  - Users can ask questions and receive answers based on website content.

- 🔍 **Retrieval-Augmented Generation (RAG)**
  - Retrieves relevant information before generating responses.
